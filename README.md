# Khanta Payment Collection Reminder

A mobile-friendly web app for tracking pending customer payments, reminders, and collections.

## Live Demo

🔗 https://ajitkhanta48.github.io/Payment-Remainder/

## Features

- Add new payment reminders
- View all pending / paid records
- Dashboard totals
- Mark payment as paid
- Delete reminder
- Search customers
- WhatsApp reminder message
- Overdue & due today highlights
- Responsive mobile design

## Tech Stack

- HTML
- CSS
- JavaScript
- Google Sheets (Database)
- Google Apps Script (Backend)
- GitHub Pages (Hosting)
